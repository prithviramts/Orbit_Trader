# Orbit Trading Lab

A local, single-user research console for one **experimental, unvalidated** rule: hold SPY when its
close is above its 200-session average, hold cash when below. It replays history honestly against two
benchmarks, teaches the concepts as you go, observes an **Alpaca paper** account, and — only after you
explicitly enable it — places supervised **paper** orders. There is no live-money route in this version.

> Not investment advice. Paper results are simulated. One good period does not show a rule works.

## Quick start (Windows, PowerShell)

```powershell
cd C:\PROJECTS\Personal\PAPER_BOT_AI
.\scripts\setup.ps1          # installs pinned deps (uv + npm), builds the dashboard, creates .env
notepad .env                 # paste your Alpaca PAPER keys locally (never into chat)
.\scripts\set-password.ps1   # hidden prompt; stores an Argon2id hash only
.\scripts\start.ps1          # starts the API/dashboard + the single trading worker
```

Open http://127.0.0.1:8765. Stop with `.\scripts\stop.ps1`. It starts in **OBSERVE** mode and stays
there until you press *Enable paper automation* on the Setup page and re-enter your password.
After an update, `.\scripts\restart-dashboard.ps1` restarts only the dashboard; the trading worker keeps running.

No credentials yet? Everything in Research and Learn works with a labelled **SAMPLE** (synthetic)
dataset. `.\scripts\mock-demo.ps1` shows a full decision → order → partial fill → exit lifecycle
against an in-memory **MOCK** broker on port 8766 without touching your real database.

## Where things are

| Path | What |
|---|---|
| `backend/orbit/strategy.py` | The rule (pure, shared by backtest and live) |
| `backend/orbit/backtest.py` | Simulator + both benchmarks + metrics |
| `backend/orbit/accounting.py` | FIFO ledger (hand-checked fixture in tests) |
| `backend/orbit/engine.py` | Live evaluation, intents, submission, reconciliation, recovery |
| `backend/orbit/broker/` | Alpaca **paper** adapter, mock broker, execution guard |
| `backend/orbit/worker.py` | The single persistent worker (file lock + DB lease) |
| `backend/orbit/api.py`, `auth.py` | Authenticated API, CSRF/Origin/Host checks |
| `backend/orbit/notify.py` | Event inbox, outbox, optional ntfy |
| `frontend/` | React/TypeScript dashboard |
| `scripts/` | setup, start, stop, test, backup, restore, restore-drill, mock-demo |
| `deploy/` | Server: Dockerfile, compose, setup/update/password scripts (not yet run on a real server) |
| `.github/workflows/ci.yml` | CI: tests, audits, typecheck/build, secret scan on every push |
| `docs/` | Setup, beginner guide, architecture, security/ops, deployment, evidence, checklist |
